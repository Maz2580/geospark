API reference

One API for every spatial answer.

REST endpoints for everything on this site. Responses are JSON. Spatial results carry their provenance (source, licence and method), units and caveats. Add ?format=geojson to get RFC 7946 GeoJSON you can open in QGIS.

Base URL

https://geospark.terrascout.app

Every path below is relative to this address.

Authentication

Authorization: Bearer <key>

Only needed when the server sets an API key. The public demo is open, with rate limits per visitor.

Machine-readable

/openapi.json

OpenAPI 3.1 for code generators and agent frameworks. Prefer a reading view? Try ReDoc.

Try it from a terminal

# Geodesic distance between two points, with its provenance
curl -s -X POST https://geospark.terrascout.app/api/v1/distance \
  -H 'Content-Type: application/json' \
  -d '{"lat_a": -37.8180, "lon_a": 144.9691, "lat_b": -37.8150, "lon_b": 144.9666}'

Using an AI agent? GeoSpark is also an MCP server: pip install geospark-ai, then add geospark-mcp to your client. See the guide.
