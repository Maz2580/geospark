What GeoSpark Does

Spatial reasoning, live data, and autonomous agents — all through one API.

🌎

Spatial Reasoning

Topology, geodesic distance, CRS transforms, buffering, area computation. All geometrically correct on the WGS84 ellipsoid — not LLM-guessed.

🤖

Autonomous Agents

Give a goal, get a complete analysis. GeoAgent plans multi-step workflows. SpatialReport generates location dossiers. SiteSelector finds optimal locations.

🌤

Live Data Channels

Real-time weather (Open-Meteo), air quality (OpenAQ), and active fire detections (NASA FIRMS). Pluggable channel architecture.

🔌

MCP Server

6 spatial tools for Claude Desktop and any MCP-compatible AI assistant. pip install geospark-ai[mcp] && geospark-mcp

📊

GeoSpark Bench

535 benchmark questions across 5 categories. LLMs score 0% on distance and ~48% on topology. With GeoSpark tools: up to 100%.

💰

Zero-Cost Stack

Local Ollama models (9 available), free APIs, no rate limits. Everything runs on your hardware or our server.

Quick Start

Install

pip install geospark-ai

Use

from geospark import Engine

engine = Engine(tools=["geocoder", "terrain"])
result = engine.ask("How far is the Eiffel Tower from Big Ben?")
print(result.spatial_context.summary)
