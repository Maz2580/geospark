01 — The proof chain

Every answer carries its own receipt.

Most AI tools give you a number. GeoSpark gives you the number, the tools that produced it, the data and licence behind each step, and a run record anyone can replay.

  1. STEP 1

    Question

    Plain words in. Places are geocoded — and when two places share a name, you're told.

    "Federation Square" → −37.8180, 144.9691
  2. STEP 2

    Tools

    The agent calls real tools — routing, Overture places, terrain — never a guess from memory.

    geocode → geocode → travel_time
  3. STEP 3

    Geometry

    Measured on the WGS84 ellipsoid and validated; swapped lat/lon is caught before it misleads you.

    geodesic · validated · RFC 7946
  4. STEP 4

    Provenance

    Sources, licences, accuracy and caveats — plus a replay that says whether the data or the code changed.

    geospark replay run.json → REPRODUCED
