# GeoSpark Project Status

Show the current state of the GeoSpark project.

## Instructions

1. Run tests: `.venv/Scripts/python.exe -m pytest tests/ -v --tb=short`
2. Count source files: `find geospark/ -name "*.py" | wc -l`
3. Count test files: `find tests/ -name "*.py" | wc -l`
4. Check installed packages: `.venv/Scripts/python.exe -m pip list`
5. Check git status (if initialized)
6. Read CLAUDE.md roadmap section and report which items are done vs pending
7. Present a summary table to the user
